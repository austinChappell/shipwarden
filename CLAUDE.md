# ShipWarden

## Writing

Write the UI text, code comments and docs in Simplified Technical English. Use short sentences, active voice and simple
tenses.

Write natural amounts of time:

- Write "a few seconds", "a few minutes" and "a few days".
- Do not write "some seconds", "some minutes" or "some days". These phrases are not natural English.

Use the progressive tense ("is ...ing" or "...ing") for work that is in progress now. This exception to the "simple
tenses" rule applies to status labels, progress messages, notices and errors about the current state:

- Write "Agent is working", "Running", "Waiting for approval" and "The agent is asking a question."
- Do not write "Agent works", "Runs", "Waits for approval" or "The agent asks a question." These phrases are not
  natural English for a current state.

Use the simple present for what always happens, for example "ShipWarden uses the saved token" or "Each agent works in
its own git worktree".
